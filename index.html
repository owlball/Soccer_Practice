About this app

This board loads real soccer drills from a Supabase database (sourced from PlayMetrics) and helps you plan and run practices for young players. There are 290 drills total; 22 are tagged specifically for this team's age group, and 16 of those actually scale down to a 6-player team.

How to use it

  • Browse drills — filter by age, category, skill level, or diagram type. Tap Play to animate real movement paths where diagram data exists.
  • Add to plan sends the currently selected drill to whichever practice is open on the Plan tab — check the plan selector there if it's not where you expect.
  • Plan practice — pick from the 8 standard practices (pre-built from approved drills) or create your own with "New plan."
  • Tap any row in a plan to expand it — that's where duration, reorder, and remove controls live, along with the drill's diagram and instructions.
  • Standard plans can be edited (durations, order, removals), but only custom plans let you add brand-new blocks like water breaks or a scrimmage. "Reset to standard" restores a standard plan's original drills if you've changed it.
  • Start session runs a live timer synced to real wall-clock time, so it stays accurate even if the screen locks mid-practice.
