About this app

This board loads real soccer drills from a Supabase database (sourced from PlayMetrics) and helps you plan and run practices for young players. There are 290 drills total; 32 are tagged specifically for this team's age group, and 23 of those actually scale down to a 6-player team and feed the 8 standard practices.

A few drills turned out to be the exact same game under a different theme -- only one version of each is used in the standard practices, and the drill you'll actually see (when you tap into it) says so:

  • Crocs in the River covers Hungry, Hungry Hippos, Boston Bulldogs, and Bruce the Shark vs Nemo -- same "cross without being caught" mechanic, different costumes.
  • Bulldogs Hunting for Milk-Bones covers Tigers vs Rabbits (Winnie the Pooh) and Good Minions vs Evil Minions -- same "hit below the knee to score" mechanic.
  • Triangle Gate Challenge with Guards covers Monsters Inc -- same triangle-zone, 2-taggers mechanic.
  • Combat to Small Goals covers Soccer Combat -- same coach-serves-a-ball, race-to-score mechanic.

How to use it

  • Browse drills — filter by age, category, skill level, or diagram type. Tap Play to animate real movement paths where diagram data exists.
  • Add to plan sends the currently selected drill to whichever practice is open on the Plan tab — check the plan selector there if it's not where you expect.
  • Plan practice — pick from the 8 standard practices (fixed, pre-built from approved drills) or create your own with "New plan."
  • Tap any row in a plan to preview it — that's where the drill's diagram and instructions show up on the right (or below, on a phone).
  • Standard plans are read-only — durations, order, and content are fixed on purpose, so they always match what's actually approved and can't drift or go stale. If you want a version you can edit, tap "Duplicate as new plan" to make your own editable copy with the same starting content.
  • An amber note on a drill means it's been adapted for a 6-player group (a tweaked rule). A blue note means it's flagging a duplicate drill under another name, like the ones listed above.
  • Start session runs a live timer synced to real wall-clock time, so it stays accurate even if the screen locks mid-practice.
